Einstellungen:
  - lbSmsAdrId   State → Visible: leer (unsichtbar, merkt sich die Adress-ID)
  - btSmsCancel  Special → TypeButton _WinBtnClose, Id 2
  - btSmsSend    Special → TypeButton NICHT _WinBtnClose (Standard lassen)
                 Key → Default LEER und ReturnKeyClick LEER
                 (sonst sendet Enter beim Tippen im Textfeld sofort)
                 Ereignisse → EvtClicked:  Sms_Dlg:EvtClicked
  - teSmsText    Ereignisse → EvtChanged:  Sms_Dlg:EvtChanged
                 Eigenschaften → AutoWrap ✓   (Zeilenumbruch am Feldende)
                 Eigenschaften → LengthMax 160 (eine SMS; im Code zusaetzlich gekuerzt)
  - btSmsLog     Ereignisse → EvtClicked:  Sms_Dlg:EvtClicked
                 Special → TypeButton NICHT _WinBtnClose (Standard lassen)
  - lbSmsFrom    zeigt den Absender aus den SMS-Einstellungen (nur Anzeige)

  Hinweis btSmsSend: Er darf das Fenster nicht selbst schliessen. Bei Fehler oder
  Testmodus muss das Fenster offen bleiben; bei Erfolg schliesst Sms_Dlg:EvtClicked es.


TEIL A2 - Fenster veränderbar machen (später)
---------------------------------------------

AreaScaling/AreaScalingFlags sind NICHT dafür da - laut Hilfe gelten sie nur für
Overlays in einem übergeordneten Objekt (DocView).

So macht es Doc_Main:
  - Frame veränderbar: AreaWidthMin 600, AreaWidthMax -1,
                       AreaHeightMin 400, AreaHeightMax -1
  - Mitwachsen der Inhalte: Gruppe "Grouping" (_WinGroupingTileVert) plus
    AlignGroupingLeftOrder / TopOrder / RightOrder / BottomOrder,
    im Code zusätzlich wpAlignMarginLeft/Top/Right/Bottom (siehe Doc_Main:View)

Vorgehen: zuerst feste Grösse 760 x 560 bauen und den ganzen Ablauf testen.
Danach als eigener Schritt Mindestgrössen setzen und das Grouping ergänzen.

TEIL B - Vorlagen-Auswahl (per Kopieren aus Doc_Main)
------------------------------------------------------

Vorbild in Doc_Main (bestätigt):

  edFromAddress : Edit
  └─ plFromAddress : PopupList
     └─ dlFromAddress : DataListPopup     4 Spalten: clmAccName, clmEmailName_Email, zzz, clmAccId

Vorgehen:

 1. Beide Masken öffnen: Doc_Main (Nur lesend genügt) und Sms_Dlg.
 2. In Doc_Main, Objektliste (F7): edFromAddress anklicken → Strg + C.
 3. In Sms_Dlg: auf den Frame klicken → Strg + V.
    Es kommen Edit + PopupList + DataListPopup mitsamt Spalten.
    Doc_Main NICHT speichern.
 4. Umbenennen (Eigenschaften F6 → Base → Name):
      edFromAddress → edSmsTpl
      plFromAddress → plSmsTpl
      dlFromAddress → dlSmsTpl
 5. edSmsTpl platzieren: AreaLeft 95, AreaTop 425, AreaWidth 365, AreaHeight 22
    (auf einer Linie mit lbTpl bei Top 430).
    Ereignisse von edSmsTpl: alle Einträge leeren, die aus Doc_Main mitkamen.
 6. Spalten von dlSmsTpl: Objektliste → Rechtsklick auf dlSmsTpl → "Spalten bearbeiten..." (F2)
      - clmEmailName_Email und zzz und clmAccId löschen (Knopf unten links mit rotem X)
      - bleibt:  clmAccName  → umbenennen in clmTplShort,  Visible ✓
      - neu:     Spalte hinzufügen (Knopf unten links) → Name clmTplText, Visible leer
      - OK
    Ergebnis: Spalte 1 = Anzeige (Anfang der Vorlage), Spalte 2 = ganzer Text (unsichtbar).
 7. Ereignisse von dlSmsTpl: EvtMouseItem = Sms_Dlg:EvtMouseItem
    (stand vorher Doc_Evt:EvtMouseItem - ersetzen). Andere Einträge leeren.
 8. Speichern.
