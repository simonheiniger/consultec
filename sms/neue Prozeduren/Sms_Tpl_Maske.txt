Maske "Sms_Tpl" — Vorlagen verwalten
====================================

Frame im Designer, Name  Sms_Tpl,  Base → Caption: Vorlagen
AreaWidth 760, AreaHeight 520

Aufruf: Knopf neben "Vorlage:" im Fenster SMS senden, und aus den SMS-Einstellungen.
Gespeichert wird wie bisher im CONZEPT-Text SMS_VORLAGEN (Blöcke, getrennt durch ---,
erste Zeile = Titel). Das Format bleibt also gleich, nur die Pflege wird bequemer.


Skizze
------

  +-----------------------------------------------------------------+
  | Vorlagen                                                    [X] |
  +-----------------------------------------------------------------+
  |  Vorlagen              Titel:                                   |
  |  +------------------+  [ Ihr Auto steht bereit            ]     |
  |  | Ihr Auto steht.. |                                           |
  |  | Terminerinnerung |  Text:                                    |
  |  |   (dlTplList)    |  +-------------------------------------+  |
  |  |                  |  |          (teTplText)                |  |
  |  |                  |  |                                     |  |
  |  +------------------+  +-------------------------------------+  |
  |  [ Neu ] [ Loeschen ]              84 / 160 - 1 SMS             |
  |                                                                 |
  |                              [ Abbrechen ]  [ Speichern ]       |
  +-----------------------------------------------------------------+

  Spalten von dlTplList (Rechtsklick → "Spalten bearbeiten..."):
    clmTplListTitle   Visible ✓     Breite ca. 240   (Titel)
    clmTplListText    Visible leer                    (ganzer Text)

Einstellungen:
  - btTplCancel   Special → TypeButton _WinBtnClose, Id 2
  - btTplSave     Special → TypeButton NICHT _WinBtnClose (Standard lassen)
                  Key → Default ✓
                  Ereignisse → EvtClicked:  Sms_Tpl:EvtClicked
                  (Der Knopf darf nicht selbst schliessen: erst speichern, dann
                   schliesst Sms_Tpl:EvtClicked das Fenster.)
  - btTplNew      Ereignisse → EvtClicked:  Sms_Tpl:EvtClicked
  - btTplDel      Ereignisse → EvtClicked:  Sms_Tpl:EvtClicked
  - dlTplList     Ereignisse → EvtMouseItem: Sms_Tpl:EvtMouseItem
  - teTplText     Ereignisse → EvtChanged:   Sms_Tpl:EvtChanged
                  Eigenschaften → AutoWrap ✓, LengthMax 160
                  (Vorlagentext ist ebenfalls auf eine SMS begrenzt)
  - edTplTitle    Ereignisse → EvtChanged:   Sms_Tpl:EvtChanged


Zusätzlich im Fenster "SMS senden" (Maske Sms_Dlg)
---------------------------------------------------

  12 Schaltflächen  Button  btSmsTplEdit  ...   Left 470, Top 425, Width 30, Height 22
     Ereignisse → EvtClicked: Sms_Dlg:EvtClicked
     Öffnet den Vorlagen-Editor; danach wird die Auswahlliste neu gefüllt.


Offen
-----
Zum Neuaufbau der Liste (nach Löschen oder nach dem Editor) fehlt mir noch der
CONZEPT-Befehl zum Leeren bzw. Löschen einer Zeile in einer DataList.
Bekannt sind bisher nur WinLstDatLineAdd, WinLstCellSet, WinLstCellGet,
WinLstDatLineInfo(_WinLstDatInfoCount) und wpCurrentInt.
